# public/

Served as-is and inlined into the single-file demo by `scripts/bundle-demo.mjs`.

- **site-default.jpg** — the aerial of the sample property the app opens with
  (29 Elliott Street, Moura QLD). Swap this file and update `DEFAULT_CUSTOMER`
  in `src/lib/defaults.js` to change the worked example. If the file is absent
  the app simply shows "No image yet" — nothing breaks.
